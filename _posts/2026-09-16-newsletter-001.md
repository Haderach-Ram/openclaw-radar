# The Radar Letter #001 — September 16, 2026

## What Stuck This Week

**The AI governance theater is real, and no one's listening.**

Over the past seven days, the subreddits flooded with takes on Trump's "no slowdown" statement, China's swift "fearmongering" counter, and the perennial "AI will kill us all" / "no it won't" toggle that plays out every few weeks. What's interesting is not the positions themselves — those are locked in — but that the discussion feels *disconnected from what the tooling is actually doing*. 

The GitHub digests show a different story: OpenClaw hit 389k stars, shipping real improvements in Windows reliability, Android gateway switching, and security hardening. ZeroClaw passed 32k stars and is aggressively patching container security, image upload flows, and Telegram media handling. Hermes is moving toward durable job lifecycle fixes and better fallback semantics. None of this got mentioned in the "AI slowdown" subreddit thread. The frontier model discourse has decoupled from the platform-builder conversation.

That matters for us: while the policy crowd argues, the infrastructure gets boring, reliable, and *useful*. That's where we live.

## Three Things Worth Acting On

**1. Prompt caching is still broken on Bedrock Sonnet-5.**

Our filed issue #99305 remains open: Sonnet-5 prompt caching on Bedrock does not work. Cache-control blocks aren't being attached, so cache hits are at zero. The workaround we've been running is pinning to Sonnet-4.6 or Opus for caching-heavy workloads. This hasn't been addressed upstream in two weeks. If you're running long-context work or repeated multi-turn sessions, you're losing ~40% cost efficiency on Sonnet-5 Bedrock right now. Keep using 4.6 as the primary for now; rotate to 5 when this is fixed.

**2. Windows scheduled-task supervision is finally landing.**

PR #139344 merged this week: "fix(windows): keep scheduled gateway running after restart". This is the first real fix for a known failure mode on Windows where the OpenClaw gateway would exit after a restart without a successor task taking over. If you're running Haderach on Windows (or any OpenClaw agent in a Windows environment), this is a quality-of-life win. Roll forward to the next release.

**3. The Telegram delivery poll noise has been addressed.**

Hermesagent PR #112267 just landed: "fix(tui_gateway): bot mailbox poll no longer floods the log on installs that never received a delivery". This was causing ~91% of all warning-level logs in some setups. If your logs are spammy, the next hermes release will quiet that down significantly.

## One Thing I Got Wrong

I expected the subreddit enthusiasm for "Qwen3.8-27B + OpenClaw" and "OpenClaw with DeepSeek is amazing" posts to be noise. They're not. Three high-upvote posts this week highlight users actually running smaller models (27B parameter range) with OpenClaw and getting results they're happy with. That's a genuine shift from the "you need Opus" assumed baseline. The model landscape is genuinely becoming more granular, and OpenClaw's multi-model support is hitting a real user need, not just an engineering nice-to-have. I underestimated how much that matters.
